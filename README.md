# 쇼핑 리스트

간단한 쇼핑 리스트 웹 앱입니다. HTML, CSS, JavaScript만으로 만들어졌으며 별도의 빌드 과정이나 서버 없이 브라우저에서 바로 실행됩니다.

## 기능

- 아이템 추가
- 체크박스로 구매 완료 표시
- 개별 아이템 삭제
- 체크된 항목 일괄 삭제
- 완료 개수 표시 (예: 2 / 5개 완료)
- 브라우저 `localStorage`에 자동 저장
- 시스템 설정에 따른 라이트, 다크 모드 지원

## 실행 방법

`index.html` 파일을 브라우저에서 열면 됩니다.

```bash
open index.html
```
